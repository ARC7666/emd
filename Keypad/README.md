# 4x4 Keypad Interfacing with Arduino UNO

## Aim
To interface a 4x4 Matrix Keypad with Arduino UNO and display pressed key characters on the Serial Monitor / Virtual Terminal.

---

## Objects / Components Required

| S.No | Component Name | Proteus Library Keyword | Quantity | Purpose |
|:---:|:---|:---|:---:|:---|
| 1 | **Arduino UNO** | `ARDUINO UNO` or `SIMULINO UNO` | 1 | Microcontroller |
| 2 | **4x4 Keypad** | `KEYPAD-PHONE` or `KEYPAD-CALCULATOR` | 1 | User input matrix |
| 3 | **Virtual Terminal** | From *Instruments Toolbar* | 1 | Serial output display |

---

## Circuit Connections

| Keypad Pin | Arduino UNO Pin |
|:---|:---|
| **Row 1 (R1)** | **Digital Pin 9** |
| **Row 2 (R2)** | **Digital Pin 8** |
| **Row 3 (R3)** | **Digital Pin 7** |
| **Row 4 (R4)** | **Digital Pin 6** |
| **Col 1 (C1)** | **Digital Pin 5** |
| **Col 2 (C2)** | **Digital Pin 4** |
| **Col 3 (C3)** | **Digital Pin 3** |
| **Col 4 (C4)** | **Digital Pin 2** |
